start creating backend:

39. create new folder outisde client filder called server and inside it create file server.js

40. initialise node package manager, that means create package.json. open console of server folder and write:
npm init -y

41. install required packages for server(backend):
npm install express cors dotenv mongoose multer

express - is a backend web application framework for Node.js. It is designed for building web applications and APIs
cors - is for help backend to connect to any frontend url
dotenv - to create environment variables in project
mongoose - to connect our project to mongoDB database
Multer - is a node.js middleware for handling multipart/form-data we use it to send text and image

42. next install new package:
npm install --save-dev nodemon

--save-dev -> this means to install this package in deveplopment environment only
nodemon - means that the package name will be nodemon

43. in package.json delete:
    "test": "echo \"Error: no test specified\" && exit 1",
and instead write:
    "server": "nodemon server.js",
it will automatically update server if any change happened.
and also add:
    "type": "module",
